# Assignment 2 static EDA outputs

Review figures and comparison tables created for the Assignment 2 field-level
EDA. The report is a separate, standalone HTML file at
`../assignment-2-eda-report-revised.html`; its figures are embedded, and this
folder also preserves the small static source figures and CSV tables for review.

The temperature figure displays daily average temperature in Fahrenheit. These
files are derived outputs only; raw runtime datasets are not included.
